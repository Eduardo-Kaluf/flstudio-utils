# flstudio-utils

Download the template and the MVAVE25 script

- Add the script to the path `C:\<FL-STUDIO-PATH>\FL Studio\Settings\Hardware\MVAVE25`
- Add the template to the path `C:\<FL-STUDIO-PATH>\FL Studio\Projects\Templates`

After that:

- Connect MIDI keyboard Mvave25
- Open FL with the default_templat.flp
- Go to options -> MIDI settings
- Click on the SMK25 displayed in the output
- Click Enable on the output and set "controller type" as M-VAVE25-custom-configuration
- Click on the MIDIOUT3 (SMK25) displayed in the output
- Click Enable on the output and set "controller type" as Mackie Control Universal
